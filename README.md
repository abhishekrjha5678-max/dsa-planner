DSA in 24 weeks (Java)
A checklist planner: 24 weeks x 5 days. Each day has one Striver video and 3 LeetCode problems with checkboxes. Progress saves in your browser (localStorage).
Put it on GitHub Pages
Create a new repo and upload all files in this folder (index.html, style.css, app.js, data.js).
Repo Settings > Pages > Deploy from a branch > main / root > Save.
Open https://<your-username>.github.io/<repo-name>/.
Customize
Edit data.js: each day is "Topic|slug slug slug". A slug is the end of a LeetCode URL (leetcode.com/problems/two-sum/).
Video links are YouTube searches for the topic. To use an exact video, edit the yt() function in app.js or add URLs.
Set a Monday start date in the page to see dates and the current week highlighted.
Progress lives per browser and per site address. Use Export/Import to back up or move devices.
