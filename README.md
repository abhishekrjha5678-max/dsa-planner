🚀 Put it online with GitHub Pages (free)
Step 1: Upload the files
Go to https://github.com/new and create a new public repository (for example dsa-planner).
Click uploading an existing file.
Upload all 5 files: index.html, style.css, app.js, data.js, README.md.
Click Commit changes.
Step 2: Turn on GitHub Pages
In your repository, open Settings, then Pages (left menu).
Under Build and deployment, set Source to Deploy from a branch.
Set Branch to main and the folder to / (root), then click Save.
Wait 1 to 2 minutes and refresh. The live link appears at the top of the Pages screen.
Official guide: https://pages.github.com
✅ How to use the planner
Open your live link.
Pick your Start date (choose a Monday). Every day then shows its date, and the current week is highlighted.
Open a week, watch the day's video, solve the 3 problems, and tick the checkboxes.
Tap Go to this week any time to jump to where you are.
Tap Export to download a backup of your progress. Use Import to restore it.
Progress is saved in your browser, per device and per website address. If you switch phone or laptop, use Export on the old one and Import on the new one.

🛠 Customize it
Change a problem or topic: edit data.js. Each day is written like this:
"Topic name|problem-slug problem-slug problem-slug"
A slug is the last part of the LeetCode link. For https://leetcode.com/problems/two-sum/ the slug is two-sum.
Use exact video links: the video buttons open a YouTube search for the topic. To link a specific video, edit the yt() function in app.js.
Change the look: edit the colors at the top of style.css.
